== filter md An upcoming content lexicon for the AT Proto Atmosphere. ## Overview - **neodoc** is a format for creating content. It's designed to be easy to use and portable without sacrificing the ability to create fully featured pages and posts. If you're familiar with [markdown](https://www.markdownguide.org/), it's like that, but on steroids. - **neodoc.style** is an upcoming [AT Proto](https://atproto.com/) [lexicon](https://atproto.com/specs/lexicon) for publishing neodocs in the [Atmosphere](https://atmosphere.community/). == endfilter
