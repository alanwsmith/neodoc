Overview == filter md **neodoc** is a writing format for creating content. It focuses on being easy to use without sacrificing the ability to make full featured posts and pages. If you're familiar with [markdown](https://www.markdownguide.org/), it's like that, but on steroids. **neodoc.style** is an upcoming1 [AT Proto](https://atproto.com/) [lexicon](https://atproto.com/specs/lexicon) for publishing neodocs in the [Atmosphere](https://atmosphere.community/). Combined, they provide a new way to publish content for feeds and sites across the Atmosphere and the wider web. The rest of this page covers the basics. Check it out and [hit me up on bluesky](https://bsky.app/profile/alanwsmith.com) if you've got questions. == endfilter
1 the neodoc parser already exists. It's embedded in my static site generator and takes care of the roughly three thousand posts on my site. I'm pulling it out to create a stand-alone library for the reference implementation to use for the lexicon.
