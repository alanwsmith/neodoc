== extends "/templates.inc/switches/default.html" == block toml title = "Documentation" created = 2026-08-07T14:28:00-04:00 id = "01/n7/c8/xg" == endblock == block content == filter md ## Pre-Defined Sections - template - for storing templates for the page that the rendering engine can use if the app allows it. An ``id`` fields must exist for the engine to pick it up. - metadata - page metadata. The `-- template:` will override the default processing template. - title - Title section for the page. The first block is treated as an h1 title by default that goes inside an hgroup tag. an optional `-- subtitle:` attribute can be added which will populate in the hgroup as well. == endfilter == endblock -- h2 Out of Scope -- list - Any type of built-in access/privacy control. Everything published to the style.neodoc lexicon is public. (Using the neodoc format in other lexicons that add permissions/privacy layers is totally acceptable and encouraged.) A specific point about this is that content items whose ``isDraft`` flag is ``true`` are public. It's up to apps to determine if/when/how they are to be shown. There is no enforcement of specific criteria. - Partial content parsing is out of scope. Parsing either completes 100% or an error is throw. Focus on making the error message as clear as possible is a priority.
